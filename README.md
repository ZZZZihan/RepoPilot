# RepoPilot

RepoPilot 是一个面向 GitHub 仓库的研发任务 Agent：从 Issue 出发，分析代码库、生成实施计划、在隔离环境中修改与验证代码，并在人工确认后创建 Pull Request。

## 第一阶段目标

输入一个本地 Python 仓库和一个 Issue，让 Agent：

1. 检索相关代码与测试；
2. 生成结构化实施计划；
3. 在批准后生成并应用 Patch；
4. 运行测试与静态检查；
5. 保存完整执行轨迹。

## 项目原则

- 首版聚焦规模较小、结果可验证的 Python 任务；
- 采用单 Agent 与确定性状态机；
- 计划执行和创建 PR 前保留人工审批；
- 所有工具调用、测试结果、错误与重试均可追踪；
- 以测试通过率、任务成功率和越权修改率作为核心评测指标。
